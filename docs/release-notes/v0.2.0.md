## v0.2.0 — 다국어 지원 / Multilingual / 多言語対応 / 多语言支持

**한국어**

- **창이 4개 언어를 말합니다** — 한국어·English·日本語·简体中文. 윈도우 언어를 따라가고, 설정 → 인터페이스 언어에서 바꿀 수 있습니다.
- **게임 언어 설정 하나로 통일** — 증강 이름을 그 언어로 받아오고, 화면도 그 언어로 읽습니다. 예전에는 두 설정이 서로 어긋날 수 있었고, 어긋나면 아무것도 인식하지 못했습니다.
- **OCR 언어 팩을 앱에서 설치** — 없으면 버튼 하나로 설치합니다. 관리자 권한 요청과 진행 상황이 보입니다.
- **OBS 위젯도 게임 언어로** — 증강 이름 옆의 "프리즘 · 11레벨" 같은 문구가 이제 클라이언트 언어를 따릅니다.
- **잘못 고른 증강 수정** — 리롤 애니메이션이 선택으로 오인되던 문제. 이제 툴팁(게임이 직접 띄운 카드 이름)이 카드 밝기보다 우선합니다.
- **영어 클라이언트 수정** — `en_us` 증강 데이터를 받아오지 못하던 문제.
- **로그는 디버그 모드에서만** — 평소에는 증강 목록만 보입니다. 디버그 모드를 켜면 판정 화면까지 저장합니다.
- **필요할 때만 재시작** — 저장 버튼이 재시작이 필요한 변경일 때만 그렇게 말합니다.

**English**

- **The window speaks four languages** — Korean, English, Japanese, Simplified Chinese. It follows your Windows language and can be changed under Settings → Interface.
- **One game-language setting** drives both halves: augment names are fetched in it and the screen is read with it. Two settings that could disagree recognised nothing when they did.
- **The OCR language pack installs from the app**, with the elevation prompt and the progress both visible.
- **The OBS widget follows the client language too** — the rarity and level beside each augment name are no longer in a second language.
- **Fixed a wrong augment being published**: a reroll animation could outshine the card actually taken. The tooltip — the game naming the card under the cursor — now outranks card brightness.
- **Fixed the English client**, which could not fetch its augment data at all.
- **The log is behind a debug switch**, which also saves the frames a pick was decided from.
- **Restarts only when a setting needs one.**

**日本語**

- **ウィンドウが 4 言語に対応** — 韓国語・英語・日本語・簡体字中国語。Windows の言語に従い、設定 → 表示言語で変更できます。
- **「ゲームの言語」設定ひとつ** でオーグメント名の取得と画面の読み取りの両方が決まります。以前は 2 つの設定が食い違うことがあり、食い違うと何も認識しませんでした。
- **OCR 言語パックをアプリから導入** — 昇格の確認と進行状況が見えます。
- **OBS ウィジェットもクライアント言語で表示** されます。
- **誤ったオーグメントが表示される不具合を修正** — リロールの演出が選択と誤認されていました。ツールチップが明度より優先されます。
- **英語クライアントの不具合を修正**（データを取得できませんでした）。
- **ログはデバッグモードのときだけ** 表示し、判定に使ったフレームも保存します。
- **再起動が必要なときだけ再起動** します。

**简体中文**

- **界面支持四种语言** —— 韩语、英语、日语、简体中文，跟随 Windows 语言，也可在 设置 → 界面语言 中更改。
- **「游戏语言」一个设置** 同时决定强化符文名称的获取语言和读屏语言。此前两个设置可能互相矛盾，一旦矛盾就什么都识别不到。
- **可从程序内安装 OCR 语言包**，能看到提权提示与进度。
- **OBS 挂件也使用客户端语言**。
- **修复了显示错误强化符文的问题** —— 重随动画会被误判为选择。现在提示框优先于卡片亮度。
- **修复了英文客户端** 无法获取数据的问题。
- **日志仅在调试模式下显示**，并会保存判定用的画面。
- **仅在需要时才重启**。
