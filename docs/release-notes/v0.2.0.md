## v0.2.0 — 다국어 지원 / Multilingual / 多言語対応 / 多语言支持

**한국어**

- 창을 한국어·English·日本語·简体中文으로 쓸 수 있습니다. 윈도우 언어를 따라가고, **설정 → 인터페이스 언어**에서 바꿉니다.
- 언어 설정이 하나로 합쳐졌습니다. 증강 이름을 그 언어로 받아오고 화면도 그 언어로 읽습니다. 전에는 두 설정이 서로 어긋날 수 있었고, 어긋나면 아무것도 인식하지 못했습니다.
- OCR 언어 팩을 앱에서 바로 설치합니다. 관리자 권한 요청과 진행 상황이 보입니다.
- OBS 위젯의 등급·레벨 표기도 게임 언어를 따릅니다. 증강 이름만 클라이언트 언어이고 나머지는 다른 언어인 상태가 없어졌습니다.
- 새로고침 연출을 선택으로 오인해 엉뚱한 증강을 올리던 문제를 고쳤습니다. 툴팁은 게임이 직접 띄운 카드 이름이라, 이제 카드 밝기보다 우선합니다.
- 영어 클라이언트에서 증강 데이터를 아예 받아오지 못하던 문제를 고쳤습니다.
- 로그는 디버그 모드에서만 나옵니다. 켜면 판정에 쓴 화면도 저장합니다.
- 저장 버튼이, 재시작이 실제로 필요한 변경일 때만 재시작한다고 말합니다.

**English**

- The window can be in Korean, English, Japanese or Simplified Chinese. It follows your Windows language and can be changed under **Settings → Interface**.
- The two language settings are now one. Augment names are fetched in it and the screen is read with it. Two settings that could disagree recognised nothing when they did.
- The OCR language pack installs from the app, with the elevation prompt and the progress both visible.
- The rarity and level beside each augment name follow the client language too, so the widget is no longer half in another language.
- Fixed the wrong augment being shown: a reroll animation could outshine the card actually taken. The tooltip is the game naming the card itself, so it now outranks card brightness.
- Fixed the English client, which could not fetch its augment data at all.
- The log is behind a debug switch, which also saves the frames a pick was decided from.
- The save button only says it will restart when a setting actually needs one.

**日本語**

- ウィンドウを韓国語・英語・日本語・簡体字中国語で表示できます。Windows の言語に従い、**設定 → 表示言語**で変更できます。
- 言語設定がひとつになりました。オーグメント名の取得と画面の読み取りが必ず同じ言語になります。以前は 2 つの設定が食い違うことがあり、食い違うと何も認識しませんでした。
- OCR 言語パックをアプリから導入できます。昇格の確認と進行状況が見えます。
- OBS ウィジェットのレアリティとレベルの表記もクライアント言語に揃いました。片方だけ別の言語になることがなくなりました。
- リロールの演出を選択と誤認して別のオーグメントを出す不具合を直しました。ツールチップはゲーム自身が出すカード名なので、明度より優先されます。
- 英語クライアントでオーグメントデータをまったく取得できなかった不具合を直しました。
- ログはデバッグモードのときだけ出ます。有効にすると判定に使ったフレームも保存します。
- 保存ボタンは、再起動が本当に必要な変更のときだけ再起動すると表示します。

**简体中文**

- 界面可使用韩语、英语、日语、简体中文，跟随 Windows 语言，也可在**设置 → 界面语言**中更改。
- 两个语言设置合并为一个。强化符文名称的获取语言与读屏语言从此一致。此前两者可能互相矛盾，一旦矛盾就什么都识别不到。
- 可从程序内安装 OCR 语言包，能看到提权提示与进度。
- OBS 挂件上的品质与等级也跟随客户端语言，不再一半是另一种语言。
- 修复了把刷新动画误判为选择、从而显示错误强化符文的问题。提示框是游戏自己给出的卡片名称，因此现在优先于卡片亮度。
- 修复了英文客户端完全无法获取强化符文数据的问题。
- 日志仅在调试模式下输出，开启后还会保存判定所用的画面。
- 保存按钮只在设置确实需要重启时才提示重启。
