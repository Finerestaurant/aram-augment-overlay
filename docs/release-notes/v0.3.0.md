## v0.3.0 — 정확도 / Accuracy / 精度 / 准确度

**한국어**

- 아수라장에 실제로 나오는 증강 247종을 우선합니다. 아레나 전용 증강과 이름이 비슷할 때만 작동하고, 후보에서 빼지는 않으므로 목록이 낡아도 정답이 사라지지 않습니다.
- 읽어낸 이름이 서로 다른 두 증강에 똑같이 들어맞으면 아무것도 올리지 않습니다. 툴팁에 가려 잘린 제목에서 실제로 일어나던 일이고, 그때는 데이터에 먼저 나오는 쪽이 올라갔습니다. 사실상 동전 던지기였습니다.
- 게임 도중에 프로그램을 다시 켜도 그 판에서 이미 획득한 증강이 남아 있습니다. 기록은 계속 저장되고 있었지만 다시 읽는 곳이 없어서, 재시작하면 목록이 비었습니다.
- 카드가 사라진 직후의 화면 효과를 선택 순간으로 오인해 엉뚱한 증강을 올리던 문제를 고쳤습니다. 선택 연출은 0.08초짜리인데 1.2초를 뒤져보고 있었습니다.
- 주소 복사가 실패하면 이유를 말합니다. 클립보드를 다른 프로그램이 잡고 있으면 잠시 후 다시 시도하고, 끝내 안 되면 주소를 로그에 적어 직접 옮길 수 있게 합니다. 전에는 눌러도 아무 일이 없었습니다.
- 프레임 기록 기능을 프로그램에서 뺐습니다. `config.json`의 `trace_mode`도 없어졌습니다. 개발용 도구로 옮겼고, 실행 파일이 그만큼 가벼워졌습니다.
- 소개 사이트가 열렸습니다 — https://finerestaurant.github.io/aram-augment-overlay/

**English**

- The 247 augments Mayhem actually draws from now rank ahead of the rest. It only matters when an Arena-only name reads similarly, and nothing is filtered out, so a list that falls behind a patch cannot put the right answer out of reach.
- When a reading fits two different augments equally well, nothing is published. This happened for real on titles the tooltip had cut short, and whichever the data file listed first was published — a coin toss with no sign it was one.
- Restarting mid-game no longer empties the list. The run was being written to disk after every pick and read back by nothing.
- Fixed the wrong augment being published from a bright effect that landed just after the cards vanished. The selection animation lasts 0.08 s and the search was reaching 1.2 s past it.
- The copy-address button says why it failed. It retries when another program is holding the clipboard, and if it still cannot, the address goes in the log so it can be typed in. It used to do nothing at all, silently.
- The frame trace is no longer in the app, and `trace_mode` is gone from `config.json`. It moved to the developer tool, and the exe is smaller for it.
- There is a site now — https://finerestaurant.github.io/aram-augment-overlay/

**日本語**

- 読み取った名前が別々の 2 つのオーグメントに等しく当てはまる場合は、何も表示しません。ツールチップに隠れて途中で切れたタイトルで実際に起きており、データに先に載っているほうが表示されていました。実質くじ引きでした。

- アドレスのコピーに失敗したとき、理由を表示します。他のプログラムがクリップボードを保持していれば少し待って再試行し、それでも駄目ならアドレスをログに残します。以前は押しても何も起きませんでした。

**简体中文**

- 优先匹配大乱斗实际会出现的 247 个强化符文。仅在与竞技场专属名称相近时起作用，且不会排除候选，因此列表滞后于版本也不会让正确答案够不着。
- 当读到的名称同样符合两个不同的强化符文时，不再显示任何内容。这在被提示框遮挡而截断的标题上确实发生过，此前会采用数据中排在前面的那个——实际上是掷硬币。
- 对局中重启程序后，本局已获得的强化符文仍会保留。此前每次选取都会写入磁盘，却没有任何地方读回。
- 修复了把卡片消失后的画面特效误判为选择瞬间、从而显示错误强化符文的问题。选择动画约 0.08 秒，而搜索却延伸到其后 1.2 秒。
- 复制地址失败时会说明原因。若有其他程序占用剪贴板会稍后重试，仍不成功则把地址写入日志以便手动输入。此前按下去毫无反应。
- 帧记录功能已从程序中移除，`config.json` 中的 `trace_mode` 也一并去除。它已移至开发工具，可执行文件因此更小。
- 介绍站点已上线 — https://finerestaurant.github.io/aram-augment-overlay/
