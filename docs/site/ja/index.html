ランダムミッド: メイヘム
オーグメント オーバーレイ

リーグ・オブ・レジェンドのランダムミッド: メイヘムで獲得したオーグメントを OBS の配信画面に表示します。画面を読み取って認識するため、アカウント連携もログインも必要ありません。

Windows 版をダウンロード GitHub で見る

選ぶたびにリストへ

1 試合でレベル 3・7・11・15 の 4 回。シルバー・ゴールド・プリズムを色で見分けます。背景が透明なので、そのまま配信画面に重なります。

OBS の隣に小さな窓がひとつ

websocket で OBS とやり取りし、ブラウザソースに貼るアドレスでウィジェットを配信します。接続と表示されれば、あとは押すものがありません。

  • OSWindows 10 / 11 — 1920×1080、拡大率 100%
  • OBS Studio28 以上
  • ゲーム設定ボーダーレスフルスクリーン推奨
  • インストールexe 1 つ。.NET ランタイムも不要
