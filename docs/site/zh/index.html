海克斯大乱斗 强化符文覆盖层

把你在英雄联盟海克斯大乱斗中获得的强化符文显示在 OBS 直播画面上。它靠读取游戏画面来识别，不绑定账号，也不用登录。

下载 Windows 版 在 GitHub 上查看

次下载 星标 复刻

每选一次就加入列表

一局四次，分别在等级 3、7、11、15。白银、黄金、棱彩用颜色区分。背景是透明的，可直接叠在直播画面上。

OBS 旁边的一个小窗口

它通过 websocket 与 OBS 通信，并在一个本地地址上提供挂件，把该地址粘贴到浏览器源即可。显示已连接之后，就没有别的要按了。

  • 操作系统Windows 10 / 11 — 1920×1080，缩放 100%
  • OBS Studio28 或更新
  • 游戏设置建议无边框全屏
  • 安装只有一个 exe，连 .NET 运行时都不需要

安装、设置与疑难解答都在 README 里 → README

基于 MIT 许可证的免费开源项目。
