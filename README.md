# 아수라장 증강 오버레이

리그 오브 레전드 **무작위 총력전: 아수라장**에서 획득한 증강을 OBS 화면에 누적 표시하는 도구입니다.
게임 화면을 읽어서 증강을 인식하므로 별도 계정 연동이나 로그인이 필요 없습니다.

- 증강 획득 순간을 자동 감지 → 이름·등급·아이콘을 오버레이에 추가
- 실버 / 골드 / 프리즘 등급을 색으로 구분
- OBS 브라우저 소스로 붙이는 방식이라 방송 화면에 그대로 올라갑니다

> 승률·티어 등 성능 지표는 라이엇 정책상 표시하지 않습니다.

---

## 준비물

| | |
|---|---|
| OS | Windows 10 / 11, **1920×1080 해상도, 배율 100%** |
| Python | 3.10 이상 ([python.org](https://www.python.org/downloads/), 설치 시 **Add python.exe to PATH** 체크) |
| OBS Studio | 28 이상 ([obsproject.com](https://obsproject.com/)) |
| 게임 설정 | **테두리 없는 전체화면** 권장 |

첫 실행 시 패키지(약 90 MB)를 내려받습니다. OCR은 Windows 내장 엔진을 쓰므로
모델 다운로드는 없습니다. 한국어 OCR 언어 팩이 없다면 실행 시 안내가 나옵니다.

## 설치 및 실행

### 1. 내려받기
```
git clone https://github.com/<사용자명>/aram-augment-overlay.git
cd aram-augment-overlay
```
또는 GitHub에서 **Code → Download ZIP** 후 압축 해제.

### 2. OBS 준비
OBS를 **한 번 실행**하고 처음 뜨는 "자동 구성 마법사"를 닫습니다.
(마법사가 떠 있는 동안에는 OBS가 설정 파일을 저장하지 않습니다.)

그다음 **OBS를 완전히 종료**하고:
```
python scripts\setup_obs.py --enable
```
websocket 서버가 켜지고 비밀번호가 출력됩니다. OBS 안에서 직접 하려면
**도구 → WebSocket 서버 설정 → 서버 활성화**도 같습니다.

### 3. 실행
OBS를 실행한 뒤:
```
run.bat
```
처음에는 가상환경 생성과 패키지 설치로 1~3분 걸립니다. 다음부터는 바로 뜹니다.

실행하면 위젯 주소가 표시됩니다:
```
위젯 주소: http://127.0.0.1:8777/
```

### 4. OBS에 위젯 붙이기
**소스 → + → 브라우저**
- URL: `http://127.0.0.1:8777/`
- 너비 `420`, 높이 `600`
- **"장면이 활성화될 때 브라우저 새로고침"** 체크 권장

배경은 투명하므로 게임 화면 위에 그대로 겹칩니다.

---

## 사용법

1. OBS 실행 (게임 캡처 소스는 도구가 자동으로 만듭니다)
2. `run.bat` 실행
3. 아수라장 게임 시작

증강을 고르면 몇 초 안에 오버레이에 추가됩니다. 새 게임이 시작되면 목록이 초기화됩니다.

## 잘 안 될 때

**"OBS 연결 실패"**
OBS가 실행 중인지, websocket 서버가 켜져 있는지 확인하세요 (`python scripts\setup_obs.py`).

**OBS를 켰더니 "안전 모드로 실행하시겠습니까?"**
반드시 **일반 모드로 실행**을 고르세요. 안전 모드는 websocket을 끄기 때문에 도구가 연결하지 못합니다.
OBS가 비정상 종료된 다음 실행에서 나타납니다.

**증강을 인식하지 못함**
- 해상도가 1920×1080, 배율 100%인지 확인 (다른 해상도는 아직 미지원)
- 게임이 **테두리 없는 전체화면**인지 확인
- OBS 게임 캡처 소스가 실제로 게임을 잡고 있는지 미리보기로 확인

**설치가 제대로 됐는지 확인하고 싶을 때**
```
.venv\Scripts\python.exe scripts\selftest.py
```
저장된 캡처로 인식 과정 전체를 점검합니다. 게임이나 OBS 없이 실행됩니다.

## 한계

- **1920×1080 전용**입니다. 화면 좌표가 이 해상도 기준으로 고정돼 있습니다.
- 증강 이름은 OCR로 읽습니다. 인식이 흔들려도 증강 이름 목록과 대조해 보정하지만,
  드물게 틀릴 수 있습니다. 인식에 실패하면 원문이 그대로 표시됩니다.
- 등급 판별과 선택 감지 임계값은 실제 플레이와 게임플레이 영상에서 측정한 값입니다.
  검증에 쓴 실버 등급 표본이 아직 적어, 실버에서 오차가 있을 수 있습니다.
- 아수라장(`gameMode: KIWI`)에서만 동작합니다.

## 동작 원리

증강 데이터는 공식 API에 **없습니다.** Live Client Data API(`127.0.0.1:2999`)의 스펙 전문을
확인했지만 증강 관련 필드가 하나도 없고, 매치 API도 아수라장 대전에는 접근이 막혀 있습니다.
그래서 화면을 읽는 방식이 유일한 경로입니다.

1. Live Client Data API로 아수라장 게임인지, 현재 레벨이 몇인지 확인
2. OBS websocket으로 게임 화면을 받아 **리롤 버튼 3개를 템플릿 매칭** → 증강 선택창 감지
3. 선택 순간 감지 — 고른 카드가 밝아지고 **나머지 두 장이 어두워지는** 패턴
4. 카드 테두리 색으로 등급 판별, 툴팁 제목을 OCR
5. 읽은 이름을 증강 목록과 대조해 확정

밝기 임계값 대신 템플릿 매칭을 쓰는 이유, 각 임계값의 측정 근거, 검증 데이터는
[`docs/FINDINGS.md`](docs/FINDINGS.md)에 정리돼 있습니다.
